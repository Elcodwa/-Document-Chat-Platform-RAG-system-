# Contributing

Thanks for your interest in contributing to the project! Please follow these guidelines to make the collaboration smooth.

- Fork the repository and create a feature branch from `main` named `feat/<short-descriptive-name>` or `fix/<short-descriptive-name>`.
- Write clear, focused commits. Use conventional commits (e.g., `feat:`, `fix:`, `chore:`).
- Open a pull request against `main` and include a short description of the change, motivation, and testing notes.
- Add or update tests for new behavior and run the test suite before opening the PR.
- Keep PRs small and scoped; large changes may be split into multiple PRs.

## Code style
- Follow the existing code style in the repository.
- For Python, run linters and formatters (e.g., `black`, `ruff`, `isort`) if present.

## Development setup
See the project's README for local development and running tests.

Thank you — we appreciate your contributions!
